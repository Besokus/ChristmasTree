# 3D 手势交互圣诞树（Three.js + 手势识别）

本项目基于 **Three.js** 与摄像头手势识别，实现一个可实时交互的 **3D 粒子圣诞树**。  
通过张开、握拳、捏合等手势，可自由控制粒子形态、圣诞树聚散、旋转以及照片抓取展示效果。

---

## 功能特点

### 1. 摄像头手势控制
支持三种核心手势：
- **握拳**：粒子聚合并形成圣诞树  
- **张开手掌**：圣诞树散开并缓慢旋转  
- **拇指 + 食指捏合**：抓取圣诞树中的照片，触发独特过渡动画  

手势变化实时响应，并经过平滑处理以保证丝滑的交互体验。

### 2. 3D 粒子系统
- 粒子由多种形状构成：圆球、礼物、圣诞袜、铃铛、领带、三角形、方块、小树、圣诞老人等  
- 粒子大小适中，并带有反光效果  
- 圣诞树顶部加入发光灯泡  
- 粒子支持聚合、散开、旋转等动态行为  

### 3. 照片抓取与展示
- 捏合手势可抓取圣诞树中的照片  
- 不同照片使用不同的入场动画效果  
- 放大展示时有光晕与丝滑过渡  
- 支持通过 UI 插入自定义照片

### 4. 简洁的现代界面
- 全屏按钮  
- 照片管理 UI  
- 轻量化，专注可视化体验  

---

## 技术栈
- **Three.js** — WebGL 3D 渲染  
- **MediaPipe Hands / TensorFlow.js** — 手势识别  
- **GLSL Shader** — 粒子、发光、过渡效果
